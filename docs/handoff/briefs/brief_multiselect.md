## Add
1. Multiple selection: Ctrl+click (Cmd+click on Mac) or Shift+click on another painted region ADDS it to the selection; the same on an already selected region REMOVES it. A plain click on a region selects only that region. A plain click on empty space clears the selection. Shift while dragging a handle still keeps proportions (Shift+click on a region that is not on a handle means add/remove; Shift during a handle drag means keep proportions).
2. Box select: press on empty space and drag draws a dashed rectangle; on release every painted region that intersects the rectangle is selected (with Ctrl/Cmd/Shift held, they are added to the current selection instead). Use the same label the existing tool would pick for each region (respect the current overlay view: only regions of visible labels can be selected).
3. Group transform: with several regions selected, show ONE bounding box with the same 8 handles around all of them; dragging inside moves all together, dragging a handle resizes all together around the group box (Shift keeps proportions), and each region keeps its own shape relative to the group exactly as `placeRegion` already does for one region (stamp from the original voxels each time, never from the previous placement).
4.
